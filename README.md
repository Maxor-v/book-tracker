## Возможности

- 📖 **Хранение книг** — название, автор, жанр, статус, оценка, рецензия, обложка.
- 🖼 **Обложки книг** — загрузка из файла с превью в списке; при отсутствии — генерируется цветной плейсхолдер с первой буквой названия.
- ✅ **Три статуса** — «В планах», «Читаю», «Прочитано» с автоматической датой завершения.
- ⭐ **Оценки 1–5** и **текстовые рецензии** для каждой книги.
- 🔖 **Закладки** — двойной клик по строке или ПКМ → «Переключить закладку».
- 🔎 **Поиск** по названию, автору и жанру в реальном времени.
- 🎛 **Фильтры** по статусу (Все / Читаю / Прочитано / В планах).
- 📊 **Статистика** — всего книг, прочитано, средняя оценка.
- 💡 **Рекомендации** — на основе жанров, которые вы высоко оценили (4–5★), подбираются книги из ваших планов.
- 🌙 **Тёмная тема** с акцентом и подсветкой выбранной строки.
- 💾 **Сохранение состояния** — позиция и размер окна, активный фильтр и поисковый запрос восстанавливаются при следующем запуске (`settings.ini`).
- 🌱 **Seed-скрипт** — 10 книг с автоматически сгенерированными цветными обложками для быстрого старта.

## Установка

### Требования

- **Python 3.9+**
- **Pillow** (единственная внешняя зависимость)
- Tkinter — входит в стандартную поставку Python на Windows/macOS. На Linux может потребоваться установка:
  ```bash
  sudo apt install python3-tk      # Debian/Ubuntu
  sudo dnf install python3-tkinter # Fedora
  ```

### Шаги

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/yourname/book-tracker.git
cd book-tracker

# 2. (опционально) Виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# 3. Зависимости
pip install -r requirements.txt
```

`requirements.txt`:
```
Pillow>=10.0.0
```

## Быстрый старт

```bash
# Заполнить БД 10 демо-книгами (один раз)
python seed.py

# Запустить приложение
python main.py
```

При первом запуске автоматически создаются:
- `books.db` — база данных SQLite
- `covers/` — папка для копий обложек
- `settings.ini` — файл с сохранённым состоянием окна

Чтобы сбросить базу и начать заново — просто удалите `books.db` и папку `covers/`, затем снова `python seed.py`.

## Как это работает

### Схема БД

```sql
CREATE TABLE books (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    title       TEXT NOT NULL,
    author      TEXT NOT NULL,
    genre       TEXT DEFAULT '',
    status      TEXT DEFAULT 'planned',  -- planned / reading / read
    rating      INTEGER DEFAULT 0,       -- 0..5
    review      TEXT DEFAULT '',
    cover_path  TEXT DEFAULT '',
    starred     INTEGER DEFAULT 0,       -- 1 = закладка
    date_added  TEXT DEFAULT CURRENT_TIMESTAMP,
    date_read   TEXT                     -- автозаполнение при смене на 'read'
);
```

### Рекомендации

1. `logic.top_genres()` — находит жанры прочитанных книг с оценкой **≥ 4**, сортирует по количеству и средней оценке.
2. `logic.recommendations()` — выбирает из **планируемых** книг те, чьи жанры попали в топ пользователя.
3. Если оценок ещё нет — показывает подсказку и последние добавленные книги.

### Сохранение состояния

При закрытии окна `App._on_close()` вызывает `settings.save(...)`, сохраняя `winfo_geometry()`, активный фильтр и строку поиска. При старте — восстанавливает.

## Управление

| Действие | Как вызвать |
|---|---|
| Добавить книгу | Кнопка **+ Добавить** в шапке |
| Редактировать книгу | Кнопка **✎ Редактировать** или ПКМ → Редактировать |
| Удалить книгу | Кнопка внизу или ПКМ → Удалить |
| Поставить/снять закладку | **Двойной клик** по строке или ПКМ → Переключить закладку |
| Начать читать книгу из планов | Вкладка **Рекомендации** → **▶ Начать читать** |
| Отметить прочитанной | Вкладка **Рекомендации** → **✓ Прочитано** или через форму |
